# Manrope

Manrope variable font, weights 400–800, Latin subset. Distributed under the SIL Open Font License in OFL-Manrope.txt.

Source CSS: https://fonts.googleapis.com/css2?family=Manrope:wght@400..800&display=swap

Font file: https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2

Upstream: https://github.com/google/fonts/tree/main/ofl/manrope

The renderer embeds the font into each report. Other scripts use the system sans-serif fallback.
