PASS if the message reports that the holder-record refresh (the storage `overwrite`) reopens the record by name without checking what it opened (no `fstat`, no regular-file check, unlike `read`), so a hard link or a file renamed over that name receives the record, or a FIFO there blocks it.
It counts in any section: a defect, a minor observation, an item outside the change, or a question.
FAIL if the message does not report it.
