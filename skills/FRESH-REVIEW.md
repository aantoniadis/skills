# Second reader

Use this guidance for a scoped check through [native delegation](WORKERS.md).
The assignment identifies the artifact, consequential questions or sections,
source conditions, existing evidence, and desired depth. Return findings without
editing the artifact unless the assignment explicitly authorizes edits.

## Read for the assigned question

For a source check, compare consequential claims with their cited sources and
records using [EVIDENCE.md](EVIDENCE.md). For a reader check, first read the
artifact without author hints and form a short account of its central answer,
conditions, next action, and missing connections. Record that understanding
before consulting source, then compare it with what the evidence supports.
This step tests whether the artifact answers the caller's domain question.

Check the parts that affect the reader's next action:

- **Support:** does the claim follow from the source or recorded run under the
  stated conditions? Preserve provenance for reused evidence. An investigator's
  conclusion alone is insufficient, but its source-backed evidence is reusable.
- **Inference to action:** does the recommendation follow? One downstream caller
  establishes exposure, not necessarily a supported API or preservation duty.
- **Reassurance:** does the inspected scope justify directing attention away from
  code? A representative edit or passing scenario establishes only its scope.
- **Usefulness:** can the reader answer the assigned question without inventing a
  connection or consequential behavior? Identify where the artifact misleads or
  omits a qualification that changes the answer.

Use existing applicable evidence. Inspect decisive sources for consequential or
conflicting conclusions; the lead need not repeat every delegated read. A fresh
context supplies another perspective, not independence from shared assumptions.

## Return and integrate

Return consequential discrepancies first, each with the artifact location,
supporting evidence, impact, and correction or open question. State the checked
scope and remaining limits, including when no discrepancy was found. In a reader
check, include the short artifact-first understanding and any material correction
from source. Use a per-claim ledger only when the assignment needs that detail.
Let the host handle communication and delivery.

The lead resolves supported findings, qualifies unsupported claims, or records
why a finding does not apply. Recheck affected conclusions and retain material
corrections with the artifact. This review neither creates user agreement nor
proves runtime behavior or publication authority.

Done when the assigned question and consequential discrepancies have evidence,
and the caller can identify what was checked and what remains uncertain.
