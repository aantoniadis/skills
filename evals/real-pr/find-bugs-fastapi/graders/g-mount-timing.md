PASS if the final message reports that `mount()` or `host()` (or a direct edit of `router.routes`) on a router that is already included is not picked up after the first request has been served, because the cached route list is not invalidated: the result depends on whether the change happened before or after the first request.
It counts in any section: a defect, a minor observation, an item outside the change, or a question.
FAIL if the message does not report it.
