# Second-reader check

Read when independent review is requested or consequential onboarding warrants a bounded second reading.

Dispatch the [second reader](../../FRESH-REVIEW.md) in reader-check mode, using [native delegation](../../WORKERS.md), supplying the learning question, the delivered note and any page, and access to the referenced revision and evidence; leave out author hints and expected findings. The domain question: can the reader predict a relevant alternative within scope and identify the code supporting it? Reuse an independent review of the same material when it already answers this need. Merely repeating the walkthrough does not answer it.

Correct supported material findings in the note and companion, and recheck the affected scenario. Record the review's scope, findings, resolutions, and unverified limits in the existing review record or a nearby `review.md`. A source-only check is not a runtime test. Without independent context, label an author self-check accurately and continue with the normal completion criteria; this review is optional.
