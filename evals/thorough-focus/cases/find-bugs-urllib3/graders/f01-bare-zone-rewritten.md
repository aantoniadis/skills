PASS if the message reports that a bare scoped IPv6 host whose zone ID looks like a percent-encoding, such as `fe80::1%41` or `::1%42`, is now silently decoded into a different address (`fe80::1a`, `::1b`) with no error, where the base kept the host as given.
It counts in any section: a defect, a minor observation, an item outside the change, or a question.
FAIL if the message does not report it.
