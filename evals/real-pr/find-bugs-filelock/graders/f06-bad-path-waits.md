PASS if the message reports that a lock path that cannot be opened as a sentinel (a directory, or a file the caller cannot read) no longer raises its `OSError`: the open error is swallowed and the caller waits or gets `Timeout`.
It counts in any section: a defect, a minor observation, an item outside the change, or a question.
FAIL if the message does not report it.
